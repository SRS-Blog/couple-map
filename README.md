# 我们的足迹 · 情侣地图

一个用来记录两个人去过哪里的网页小项目。点开地图上的省份，它会自然放大，再点进城市和区县，
把照片、视频和当时的心情钉在那里。记录下来的地方会在地图上亮起来。

所有东西都存在你自己电脑上，不联网、不上传、没有账号。

---

## 怎么跑起来

**Windows 上最简单**：双击 `start.bat`。第一次会自动下载地图数据，然后打开浏览器。

**手动跑**：

```bash
node tools/fetch-geo.mjs   # 只需第一次，下载地图边界数据
node server.mjs            # 启动本地服务
```

然后浏览器打开 <http://localhost:5200>。

需要 Node.js 18 以上（用了内置的 fetch）。端口被占用会自动往后顺延一个。

---

## 玩法

- **点省份** → 地图平滑放大，展开这个省的城市
- **再点城市** → 继续放大到区县
- **点区县**（或双击任何一级）→ 右边滑出记录面板
- 写标题、选日期、挑个心情、写点话、拖照片视频进来 → 保存
- 保存后那块区域会**亮起来**，冒出一捧爱心，地图上的爱心标记数字 +1

其它：

| 功能 | 说明 |
| --- | --- |
| 🎲 回忆漫游 | 随机抽一段回忆，地图自动带你飞过去（快捷键 `R`） |
| 🖼 回忆墙 | 所有回忆的瀑布流，可以按省份、标签筛选，也能搜正文（快捷键 `G`） |
| 🌙 / ☀️ | 白天是奶油玫瑰粉，夜晚是深玫紫 |
| ⚙️ 设置 | 改名字、在一起的第一天、签名；备份、导出导入、打开照片文件夹 |
| 滚轮 / 拖动 | 缩放和平移地图 |
| 右侧滑条 | 0% 是全国视图，100% 是最深放大，按对数刻度；滚轮和点进省市时会跟着同步 |
| ⟲ | 回到全国 |
| 🎵 右下角黑胶 | 点唱片打开歌单；播放时唱片和外圈流光一起转，曲子一首接一首轮播 |

地图上爱心里的数字，是这个区域（含下级）一共有多少段回忆。
颜色分三档，跟左下角图例对得上：还没去过是浅底色，去过一次亮起来，去过两次以上更深一档。

## 音乐播放器

右下角那张**黑胶唱片**就是播放器。打开页面会自动播放，右上角点「＋ 上传」把你们的 MP3 丢进来
（也支持直接把文件拖到播放器上），有多首就**依次轮播**，最后一首放完回到第一首。

- **点唱片** → 展开 / 收起歌单卡片
- **▶ / ⏮ / ⏭** → 播放暂停、上一首、下一首
- **点进度条** → 跳到任意位置
- **🔊** → 调音量，再点一下静音
- **鼠标移到曲目上** → 出现 ✕ 可以删掉这一首

播放的时候唱片本身会转，外面还有一圈流光跟着转。记住你上次的曲目、音量，
以及是「想听」还是「手动暂停过」——暂停过的话下次打开不会再吵你。

> 浏览器默认不允许网页自动出声。如果唱片旁边冒出「点一下开启音乐 ♪」，
> 在页面上随便点一下就会接着放了。这是一次性的，之后都能正常自动播放。

## 数据都在哪儿

```
couple-map/
├── data/
│   ├── records.json      ← 所有文字记录、设置（就是个 JSON，可以直接看）
│   ├── music.json        ← 歌单清单
│   ├── media/            ← 你上传的照片和视频，按记录 id 分文件夹
│   │   └── r_xxxx/       ← 一条回忆一个文件夹
│   ├── music/            ← 你上传的歌曲音频
│   └── geo/              ← 地图边界数据（下载来的，删了可以重新下载）
├── backups/              ← 点「立即备份」后生成的整份副本
├── public/               ← 前端页面
├── server.mjs            ← 本地服务
└── tools/fetch-geo.mjs   ← 地图数据下载脚本
```

想换电脑：把整个 `data/` 目录拷过去就行。或者用设置里的「导出」拿到一份 JSON，
配合 `data/media` 一起搬。

**备份建议**：偶尔点一次设置里的「立即备份」，会在 `backups/` 里生成一份完整副本。

## 地图数据来源

省 / 市 / 区县三级边界来自阿里云 [DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)。
`tools/fetch-geo.mjs` 会把它们下载到 `data/geo/`，之后完全离线可用。

投影用的是 Albers 等积圆锥投影（中央经线 105°E，标准纬线 25°N / 47°N），
这是中国地图的常用参数。所有层级共用同一套投影，放大靠动画改 SVG 的 `viewBox`，
所以层级切换时几何完全连续，看起来就像镜头推近。

```

└── js/
    ├── app.js         入口，把各模块串起来

    ├── gallery.js     回忆墙 + 设置
    ├── ui.js          弹窗、toast、大图查看器、地区选择器、爱心特效
    └── api.js         和本地服务通信
```
